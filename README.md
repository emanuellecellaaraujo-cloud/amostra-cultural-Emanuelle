# 🐍 Atividade Prática em Python

Este repositório contém a entrega da atividade prática proposta no curso, focada no desenvolvimento de um script funcional em Python e na criação de uma documentação técnica clara utilizando Markdown.

## 📋 Sobre o Projeto

O arquivo `script.py` é uma aplicação de terminal que simula uma **Calculadora de Média Escolar**. O programa solicita o nome do aluno e suas notas, realiza o cálculo da média aritmética e exibe o status final (Aprovado, Recuperação ou Reprovado) com tratamento básico de erros.

## 🚀 Funcionalidades

* **Entrada de dados interativa:** Captura o nome e as notas do usuário via terminal.
* **Cálculo automatizado:** Calcula a média e formata o resultado com uma casa decimal.
* **Classificação condicional:** Verifica se o aluno atingiu a média necessária para aprovação.
* **Tratamento de exceções:** Evita que o programa quebre caso o usuário digite letras no lugar de números.

## 🛠️ Pré-requisitos

Para executar este projeto, você precisará ter instalado em sua máquina:
* [Python 3.x](https://python.org)

## ⚙️ Como Executar o Código

1. **Baixe o arquivo** `script.py` para o seu computador (ou clone este repositório).
2. **Abra o terminal** (Prompt de Comando, PowerShell ou Terminal do Linux/Mac).
3. **Navegue até a pasta** onde o arquivo `script.py` foi salvo:
   ```bash
   cd caminho/para/a/pasta/atividade-python-pratica
   ```
4. **Execute o script** com o comando:
   ```bash
   python script.py
   ```
   *(Nota: No Linux ou macOS, utilize `python3 script.py`)*
